# starlink-widget

Starlink-Widget für die Omarchy-Bar: Verzögerung in der Bar, Klick-Panel mit Zustand und Grund eines Unterbruchs.

- `plugin/` wird nach `~/.config/omarchy/plugins/dd.starlink` verlinkt (Symlink).
- `bin/starlink-status` fragt die Schüssel ab und nutzt die Python-Umgebung von `~/Work/starlink-grpc-tools`.
